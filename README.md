東京在住。バックエンドと SRE の境界を中心に仕事をしています。 作ることよりも、壊れたときにどう分かるか・安全に戻せるかに時間を使うようになりました。

測っていないことは「未検証」と書く。これだけは守っています。

公開しているもの
ecommerce-msa-portfolio 13サービスの EC マイクロサービス。設計から本番運用まで一人で。 Outbox パターン / Saga / SLO とエラーバジェット / 無停止スキーマ変更 / 自動切り戻しを含むデプロイ。小規模ながら実際に動いています。

sql-tuning-lab PostgreSQL のクエリチューニングを、推測ではなく測定で確かめたラボ。 27個の実験結果を数値つきで残しています。 途中、自分の測定値が100倍以上ずれていたことに気づいて訂正しました。

web-security-lab Web の脆弱性を、攻撃側と防御側の両方から実装して確認したラボ。 WebAuthn、CSP、セッション管理など。
